# Decoded H13 residency facts used by round 3

These records retain parameters, hashes and decoded task fields from the
round-2 compile-only campaign. They contain no Apple object or kernel bytes.
The compiler tool hash is recorded in each file. The original decoded
`task_descriptors` are unchanged; unrelated program-address records and
constant-section statistics were removed.

The c128/c160 56x56 triplets prove the complete terminal 0x120/0x142 form.
The c176/c192/c256 triplets demonstrate that compute row bands retain a full
56-row inter-layer edge and that the second edge spills. The forced
c2048/c4096 cases prove the multi-task protocol independently of the open
encoder's task-count choice. The six-layer c1024/7 case proves the ordinary
7-row geometry. They are descriptor evidence, not device execution evidence.
